## Rollback after a client test

The guarded installer retains the immediately prior addon tree, each existing `AddOns.txt`, and each existing `ErrandMaster.lua`/`ErrandMaster.lua.bak` under `Interface/ErrandMaster-backups`, outside active `AddOns`. It hashes copies before the swap, restores the prior addon on failure, and leaves backups if recovery fails. Independent readback compares retained copies and current save/state file hashes without displaying contents. QuestieDB remains separately managed and unchanged.

If WoW has loaded the feedback build, close it before reverting. Preserve newer saves separately; restore the matching prior addon tree and, only if a compatibility issue requires it, its matching preinstall SavedVariables and `AddOns.txt` backups. Verify exact file hashes and the stopped process before relaunching. Reverting an older save discards later errands; keep both copies and choose deliberately. Leave QuestieDB alone. Do not inspect or modify SavedVariables while WoW runs.

## Known limitations and later work

- The 400-node per-character trail cap stops recording and warns rather than silently replacing accumulated evidence. `/em trails status` shows counts; `/em trails clear` requires a second confirmation and deletes the current character's observations. Long journeys require a separately designed, tested compaction/retention policy; do not silently prune user evidence.
- Ordinary manually entered pins usually lack trustworthy world elevation, so proximity to an observed node does not establish a fully known route. Keep these partial until a safe destination-evidence mechanism is proved live.
- Native APIs do not provide a complete NPC-coordinate catalog or terrain navmesh. QuestieDB is a runtime provider, not a bundled catalog; its coverage, licensing for any future redistribution, and exact Forever-build relevance have not been established in the live client. A map with more than 10,000 service records is explicitly labeled incomplete. Cross-map travel, boats, portals, hazards, enemy density and faction restrictions are not routed. Stop ordering is greedy, not globally optimal.
